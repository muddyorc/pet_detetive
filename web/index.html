Chave de API

O sistema funciona sem chave: o perfil e as respostas saem do modelo local. A chave só habilita o botão de aprofundar na nuvem. O provedor é reconhecido pelo prefixo.

Gravada em .env, que está no .gitignore — não vai para o GitHub. A foto continua nunca saindo daqui: para a nuvem vão apenas o nome da raça, a sua pergunta e o texto da base local.

As respostas são ancoradas na base de conhecimento local. A pergunta aberta é a tarefa difícil, então vai para o modelo em nuvem; o perfil, que é sempre o mesmo texto, fica aqui na máquina. Sem chave ou sem rede, tudo cai no modelo local.

A rede compara a foto com 37 raças puras e mede semelhança visual, não ascendência genética. A sua foto não sai desta máquina: ela é processada em memória, nunca é gravada em disco e nunca é enviada para a nuvem. Só o nome da raça e o texto da base de conhecimento local são usados para escrever o perfil.
